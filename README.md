# TakaCode

> **Avec TakaCode, chacun peut trouver une voie dans le numérique, développer des compétences et les transformer en projets concrets. Un projet réalisé peut devenir une expérience, une preuve de compétence, un produit, une activité ou une opportunité.**

## Le problème

De nombreux jeunes et adultes veulent améliorer leur situation professionnelle et économique, mais **ne savent pas toujours par où commencer ni comment progresser jusqu'à une première opportunité concrète**.

Certains n'ont pas encore de compétence directement valorisable. D'autres ont suivi une formation ou appris un métier, mais manquent d'expérience pratique pour démontrer ce qu'ils savent faire. D'autres souhaitent se reconvertir, entreprendre ou créer une source de revenus, sans savoir quelle voie choisir ni comment passer de l'apprentissage à l'action.

Le problème n'est donc pas seulement l'accès à la formation.

**Il existe un écart entre apprendre, savoir faire, avoir une idée et réussir à transformer tout cela en expérience, en projet réalisé et en opportunité économique.**

Entre l'orientation, l'acquisition de compétences numériques, la mise en pratique, la réalisation d'un premier projet et l'accès aux premières opportunités, le parcours peut être difficile à franchir seul.

Cette difficulté contribue notamment au chômage, au sous-emploi, à la précarité professionnelle et à l'exclusion économique, particulièrement chez les jeunes et les personnes en transition professionnelle.

## La réponse de TakaCode

**TakaCode accompagne le passage de l'orientation à l'action à travers les métiers, les projets et l'entrepreneuriat numériques.**

La plateforme permet à chacun de partir de sa situation actuelle :

* avec ou sans compétence ;
* avec ou sans idée précise ;
* avec ou sans expérience ;
* pour apprendre un métier du numérique, se réorienter, entreprendre ou développer une activité.

TakaCode aide progressivement le membre à **identifier une direction, acquérir les compétences dont il a besoin, les mettre en pratique et construire un projet concret jusqu'à sa réalisation.**

Le projet devient ainsi un outil d'apprentissage, d'expérience et d'insertion.

Il peut permettre de construire un portfolio, démontrer une compétence, tester une idée, proposer un service, lancer un produit digital, démarrer une activité freelance, créer un outil numérique, répondre à un besoin réel ou générer une première source de revenus.

> **L'objectif n'est pas uniquement d'apprendre. L'objectif est de transformer l'apprentissage en capacité d'agir.**

## Le numérique comme terrain d'opportunités

TakaCode se concentre principalement sur **les compétences, les métiers, les projets et les produits liés au numérique**.

Cela inclut notamment :

* le développement web et logiciel ;
* l'intelligence artificielle ;
* la data ;
* l'automatisation ;
* le no-code et le low-code ;
* la création de contenu numérique ;
* le e-commerce ;
* les produits digitaux ;
* les services numériques ;
* le freelancing ;
* et l'entrepreneuriat numérique.

L'objectif n'est pas que chaque membre devienne développeur.

**L'objectif est que chacun puisse identifier une voie dans l'économie numérique, acquérir les compétences nécessaires et les mettre en pratique à travers des réalisations concrètes.**

# TakaCode ne crée pas de formations

TakaCode n'a pas vocation à produire une nouvelle bibliothèque de cours ni à remplacer les ressources pédagogiques qui existent déjà sur Internet.

Il existe aujourd'hui une quantité considérable de ressources accessibles gratuitement ou librement : documentations officielles, vidéos YouTube, tutoriels, articles, cours ouverts, guides pratiques, dépôts GitHub, communautés, outils interactifs et contenus spécialisés.

**Le problème n'est pas toujours l'absence de ressources. Le problème est souvent de savoir quoi apprendre, dans quel ordre, à quel moment et surtout comment l'appliquer à un projet réel.**

TakaCode agit donc comme **une couche de structuration, d'orientation et de mise en pratique**.

La plateforme sélectionne et organise des ressources existantes dans des parcours adaptés à la réalisation d'un projet.

Un membre n'apprend pas un ensemble de notions de manière abstraite avant de commencer.

Il avance dans son projet, rencontre un besoin précis, puis TakaCode lui propose les ressources utiles à ce moment-là.

Cela peut être :

* une documentation officielle ;
* une vidéo YouTube ;
* un article ;
* un tutoriel ;
* un exemple de code ;
* un dépôt GitHub ;
* une ressource communautaire ;
* un outil interactif ;
* un guide pratique ;
* ou toute autre ressource pertinente accessible en ligne.

Le principe est simple :

> **Nous ne recréons pas ce qui existe déjà. Nous organisons les meilleures ressources disponibles autour d'un objectif concret : réaliser un projet.**

TakaCode transforme ainsi des ressources dispersées en **parcours cohérents, contextualisés et orientés vers l'action**.

---

# L'apprentissage au fil du projet

Sur TakaCode, l'apprentissage suit la progression du projet.

Le membre n'a pas besoin de terminer une longue formation avant de commencer à construire.

Il apprend **au moment où il en a besoin**.

Par exemple :

**Objectif du projet → Étape à réaliser → Compétence nécessaire → Ressource adaptée → Mise en pratique immédiate → Livrable suivant**

Cette approche permet de réduire la distance entre théorie et pratique.

Chaque ressource doit avoir une raison d'être dans le parcours : **elle aide à franchir une étape concrète du projet.**

Ainsi, TakaCode ne cherche pas à mesurer uniquement :

* le nombre de vidéos regardées ;
* le nombre de cours terminés ;
* le nombre d'heures de formation.

La plateforme cherche surtout à mesurer :

* ce que le membre a compris ;
* ce qu'il a appliqué ;
* ce qu'il a construit ;
* les livrables qu'il a produits ;
* les compétences qu'il a démontrées ;
* et la progression réelle de son projet.

> **La ressource sert l'apprentissage. L'apprentissage sert le projet. Le projet sert l'expérience et l'opportunité.**

# L'intelligence artificielle comme accélérateur

TakaCode considère l'intelligence artificielle non comme un substitut à l'apprentissage, à l'effort ou à la réflexion, mais comme **un outil capable d'augmenter considérablement la capacité d'une personne à apprendre, créer et produire lorsqu'il est correctement maîtrisé.**

Nous ne pensons pas que l'utilisation de l'IA doive conduire à moins apprendre ou moins réfléchir.

Nous pensons qu'une personne qui comprend ce qu'elle fait et sait utiliser intelligemment les nouveaux outils peut **apprendre plus vite, résoudre certains problèmes plus efficacement, automatiser des tâches répétitives et consacrer davantage de temps à la création de valeur.**

> **L'IA ne remplace pas la compétence. Bien utilisée, elle peut la démultiplier.**

C'est pourquoi TakaCode intègre progressivement l'intelligence artificielle dans l'ensemble du parcours : non seulement comme une compétence à découvrir, mais également comme **un outil transversal au service de la réalisation des projets.**

Un membre peut ainsi apprendre à utiliser l'IA pour rechercher, comprendre, créer, coder, analyser, automatiser, produire du contenu, structurer une idée ou résoudre un blocage.

Mais l'objectif reste toujours le même : **faire progresser le projet et développer la capacité du membre à agir par lui-même.**

## Le Coach IA TakaCode

TakaCode intègre un **agent IA capable de jouer le rôle de coach tout au long du parcours**.

Il peut notamment aider un membre à :

* clarifier son objectif ;
* identifier les compétences dont il a besoin ;
* comprendre une notion ;
* décomposer un projet complexe en étapes ;
* sélectionner ou recommander une ressource adaptée ;
* expliquer comment utiliser une documentation ;
* préparer son prochain livrable ;
* trouver des ressources pertinentes ;
* analyser un blocage ;
* obtenir un retour sur son travail ;
* progresser lorsqu'aucun mentor humain n'est immédiatement disponible.

Le Coach IA ne remplace pas la communauté, les mentors ou les experts.

Il constitue **une première couche d'accompagnement disponible pour aider le membre à continuer d'avancer**, tandis que l'intervention humaine conserve toute sa valeur pour l'expérience, le jugement, le feedback, le réseau et les situations nécessitant une expertise plus approfondie.

Le modèle d'accompagnement devient ainsi :

**Membre + Ressources ouvertes + IA + Communauté + Mentors + Experts → Projet réalisé**

## Proposition de valeur sociale

**TakaCode accompagne les jeunes et les personnes en transition professionnelle de l'orientation à l'action dans l'économie numérique, en structurant des ressources accessibles autour de projets concrets afin de transformer l'apprentissage en compétences pratiques, les compétences en réalisations et ces réalisations en opportunités professionnelles ou entrepreneuriales.**

En une phrase :

> **TakaCode réduit l'écart entre formation et insertion économique en transformant des ressources d'apprentissage accessibles sur Internet en parcours structurés autour de projets numériques concrets, avec l'intelligence artificielle comme accélérateur.**

## Ambition d'impact

TakaCode ambitionne de contribuer à **l'employabilité, l'insertion professionnelle, l'entrepreneuriat et l'autonomisation économique**, en particulier pour les personnes qui manquent d'expérience, d'accompagnement ou de cadre pour passer à l'action.

À travers cette approche, TakaCode cherche à agir sur plusieurs facteurs pouvant contribuer au chômage, au sous-emploi et à la vulnérabilité économique :

* manque d'orientation ;
* manque de compétences numériques pratiques ;
* difficulté à identifier les ressources réellement utiles ;
* difficulté à transformer des ressources dispersées en parcours cohérent ;
* difficulté à transformer une formation en expérience ;
* absence de réalisations permettant de démontrer ses capacités ;
* difficulté à accéder aux opportunités de l'économie numérique ;
* difficulté à démarrer une activité professionnelle ou entrepreneuriale ;
* manque d'accompagnement dans le passage à l'action ;
* maîtrise insuffisante des nouveaux outils d'intelligence artificielle et de productivité.

TakaCode ne prétend pas résoudre seul la pauvreté ou le chômage. La plateforme cherche à **créer des chemins plus accessibles vers les compétences, l'activité économique et l'autonomie professionnelle dans une économie de plus en plus numérique et augmentée par l'intelligence artificielle.**

# Qu'est-ce qu'un projet sur TakaCode ?

Chez TakaCode, **un projet numérique ne signifie pas forcément développer un logiciel**.

Un projet est une réalisation concrète avec un objectif, des étapes et des livrables.

Il peut s'agir, par exemple, de :

* créer un SaaS ;
* développer un agent IA ;
* créer une automatisation ;
* lancer une boutique en ligne ;
* créer une formation ;
* lancer une chaîne YouTube ;
* produire un podcast ;
* démarrer une activité freelance ;
* créer un produit digital ;
* développer un site ou une application ;
* mettre en place un service numérique ;
* répondre à un besoin réel d'une organisation ;
* ou réaliser tout autre projet permettant d'apprendre, de démontrer une compétence, de créer de la valeur ou de développer une activité.

Chaque projet devient un **parcours concret**, avec des étapes à franchir, des ressources à mobiliser et des livrables à produire jusqu'à sa réalisation.

> **Sur TakaCode, on n'apprend pas seulement pour savoir. On apprend pour faire.**

# Trois façons de commencer

TakaCode ne suppose pas que chaque membre arrive avec une idée ou des compétences.

Il existe trois principales portes d'entrée.

### BUILD — « J'ai une idée »

Le membre sait déjà ce qu'il souhaite réaliser.

TakaCode l'aide à transformer son idée en projet structuré, à identifier ce qu'il doit apprendre ou mobiliser, puis à avancer étape par étape jusqu'à sa réalisation.

Les ressources proposées évoluent donc avec les besoins réels du projet.

### CHALLENGES — « Je veux construire, mais je ne sais pas quoi »

Le membre veut apprendre, progresser ou construire quelque chose, mais n'a pas encore de projet.

Les Challenges lui proposent des projets à réaliser pour **apprendre par la pratique, découvrir des métiers du numérique, développer des compétences et constituer progressivement des preuves de ce qu'il sait faire.**

Chaque Challenge combine :

**un objectif concret + des étapes + des ressources accessibles + des livrables à produire.**

### MISSIONS — « Je veux contribuer à un besoin réel »

Le membre met ses compétences en pratique sur un besoin concret proposé par une organisation, une communauté, un projet ou un autre acteur.

Les Missions rapprochent ainsi **apprentissage, expérience et réalité professionnelle.**

# Une plateforme centrée sur la réalisation

TakaCode ne cherche pas à devenir une nouvelle plateforme de cours.

**Nous ne voulons pas produire davantage de contenu là où des ressources de qualité existent déjà. Nous voulons rendre ces ressources réellement actionnables.**

Les ressources pédagogiques sont un moyen.

**Le projet est le fil conducteur.**

Lorsqu'un membre doit apprendre quelque chose pour avancer, TakaCode l'oriente vers les connaissances, ressources, outils, personnes ou expériences nécessaires.

Il apprend parce qu'il en a besoin pour progresser.

Il consulte une ressource pertinente.

Il peut utiliser le Coach IA pour mieux la comprendre ou l'appliquer.

Il met immédiatement ce qu'il apprend en pratique.

Il produit des livrables.

Il reçoit de l'aide lorsqu'il est bloqué.

Il termine quelque chose qu'il peut montrer.

La progression recherchée est donc :

> **« Je ne sais pas quoi faire » → « J'ai trouvé une direction » → « Je commence un projet » → « J'apprends ce dont j'ai besoin » → « J'utilise les bons outils » → « Je pratique » → « Je construis » → « J'ai réalisé quelque chose » → « Je peux le valoriser ».**

# Communauté et accompagnement

TakaCode repose également sur une logique d'entraide.

Les membres ayant déjà réalisé des projets ou développé une expérience peuvent progressivement aider ceux qui commencent ou rencontrent des difficultés.

L'intelligence artificielle fournit une première couche d'accompagnement, tandis que la communauté apporte ce que la technologie seule ne peut pas fournir : **expérience vécue, jugement, feedback humain, collaboration et réseau.**

Les principaux rôles sont :

* **Visiteur** — découvre TakaCode sans avoir encore de compte ;
* **Membre** — possède un compte et utilise la plateforme ;
* **Builder** — construit son propre projet ;
* **Contributor** — contribue à un projet ou une mission ;
* **Mentor** — accompagne d'autres membres grâce à son expérience ;
* **Expert** — apporte une expertise spécifique lorsqu'elle est nécessaire.

Les définitions précises et les règles associées à ces rôles sont documentées dans [VISION.md](./VISION.md).

# La boucle TakaCode

TakaCode cherche à créer une boucle dans laquelle chaque réalisation peut ouvrir la voie à la suivante :

**Découvrir → S'orienter → Trouver les bonnes ressources → Apprendre → Construire → Terminer → Montrer → Contribuer → Créer une opportunité → Aider d'autres personnes**

Un membre peut commencer sans compétence ni expérience, découvrir un métier numérique, réaliser ses premiers Challenges, devenir Builder, terminer plusieurs projets, contribuer à des Missions puis, avec suffisamment d'expérience, devenir Contributor, Mentor ou Expert.

> **Celui qui avait besoin d'aide hier peut devenir celui qui aide demain.**

# Lancer le projet en local

```bash
npm install
npm run dev
```

# Variables d'environnement

Copier `.env.example` vers `.env.local`, puis renseigner les variables nécessaires.

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...

# Administrateurs bootstrap
TAKACODE_ADMIN_EMAILS=toi@exemple.com

# Revue IA des micro-projets
AI_REVIEW_PROVIDER=openrouter
AI_REVIEW_FALLBACK=gemini,huggingface
AI_REVIEW_OPENROUTER_API_KEY=sk-or-v1-...
```

Les modèles disponibles et les clés spécifiques à chaque fournisseur sont documentés dans `.env.example`.

# Initialiser la base Supabase

Deux familles de scripts doivent être exécutées dans l'ordre.

## 1. Scripts SQL numérotés

Exécuter les scripts `supabase/sql/001` à `supabase/sql/026` dans l'ordre depuis le SQL Editor de Supabase.

Dans `002_bootstrap_admin.sql`, remplacer `EMAIL_PLACEHOLDER` par l'adresse e-mail de l'administrateur.

Le seed principal des parcours se trouve dans `005`, complété par `019` à `025` pour la banque de questions et les contenus additionnels.

## 2. Migrations CLI

```bash
supabase db push
```

Cette commande applique les migrations présentes dans `supabase/migrations/`.

Puis :

```bash
# Créer ou promouvoir un administrateur
node scripts/bootstrap-admin.mjs --email toi@exemple.com --password "MotDePasseFort"

# Restaurer les accents et apostrophes du contenu
node scripts/fix-french-content.mjs --apply

# Parcours "Création de contenu avec l'IA"
node scripts/seed-creation-contenu-ia.mjs

# Parcours "Produits digitaux : créer et vendre"
node scripts/seed-produits-digitaux.mjs

# Parcours avancés
node scripts/seed-parcours-avances.mjs

# Suggestions de liens d'affiliation
node scripts/seed-affiliations-suggestions.mjs

# Module plateformes de vibe coding
node scripts/seed-vibe-plateformes.mjs
```

# Build

```bash
npm run build
npm start
```
